The ladder3 / 8

Four gates. Each asks for different evidence.

1 · Checks

static
Reads the code without running it. Scans the description. Pins a hash.

2 · Staging

behavior
Runs in the sandbox. Sees only files it declared. Runs tests it wrote itself.

3 · Approval

human
A person reads the diff and the manifest. Only a typed yes counts.

4 · Registry

integrity
Keeps its own copy. Re-hashes it on every load. Served over MCP.

Finding 47 / 8

Evaluation infrastructure fails in boring ways.

1An unfair first run

A bug of mine hid the model's own test files from its tool. Every test crashed. Fixed, and the first result is kept in the repo, labelled.

2A reply cap that hid models

Reasoning models spend the cap on hidden thinking. At 12,000 tokens, minimax went from 3.3 to 5.0 of 6, and 9 empty replies became 0.

3A cost counter 3× too low

I estimated about $5. The dashboard said about $15. Hidden reasoning tokens were not counted. Fixed: the router now uses the provider's own number.
